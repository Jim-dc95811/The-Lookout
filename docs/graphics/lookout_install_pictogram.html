THE LOOKOUT

From the box to a live map
A pocket router that shows your units — and you — on an offline map, on any screen. Nothing to install on the viewer.
You need the internet only once — just for the router setup. After that, the box never needs it again. Freeze it and run it forever, offline.
FirstGet ready on a regular computerbefore anything else
1

Build your maps as .tpkx

Make your offline maps with the ArcGIS Earth Unlocked map tools, saved as .tpkx (not MBTiles): one file serves both the browser map and ArcGIS Earth, and JPG tiles keep it small.

Build several if you like — each one gets its own link on the box.
2

Copy your maps to the SSD — root, top level

Plug the SSD into your computer and copy your .tpkx file(s) onto the root — the top level of the drive, not inside a folder.

The Lookout serves every map it finds on the drive's top level, each with its own link.
3

Install Python on your computer

The map tools and Lookout Manager (the setup app) are Python programs, so your computer needs Python 3 — from python.org; tick Add to PATH.

One install covers both making maps and running the setup app.
Set upTurn a new router into The Lookoutinternet needed · ~5 minutes · once
4

Power up the router

Plug in the power adapter. Give it about a minute to boot and bring up its Wi-Fi.

5

Give it internet

Run an Ethernet cable from your home router or modem into the GL's WAN port (marked on the back).

Just for setup — unplug it after.
6

Connect your laptop

Plug your laptop into a LAN port, or join the router's Wi-Fi. The name and password are on the sticker underneath.

7

Set the admin password

Open a browser to 192.168.8.1. The GL welcome screen asks for a language and a new admin password — set it.

Remember it — it's also the router's SSH login.
8

Run Lookout Manager → Set up this router

On the laptop, open Lookout Manager, type 192.168.8.1 and that password, and click once. It installs everything over SSH (incl. Python on the router) and starts it.

★ The one technical step — and it's one button (~2–3 min).
9

Now unplug the internet

Setup's done. Pull the WAN cable — the box never needs the internet again. Everything from here is offline.

Freeze it on this firmware and forget it.
Plug inHang the field kit off the USB huboff-the-shelf parts · no internet
10

Connect the hub to the router

Plug the hub's host cable into the router's USB port and into the hub's one dedicated INPUT port — not one of the four device ports. Power the hub from 12 V.

The INPUT port is the single upstream port (your unit marks it). The four others are for devices.
11

Plug the radio, GPS and SSD into the hub

All three go into the hub's four device ports — any port, any order.

  • Radio — the fleet (every unit that keys up)
  • GPS — you ("you are here"); read directly, no drivers
  • SSD — your maps (the one you loaded first)
See itLive on every screen — nothing installedoffline · any device
12

Open the map — on anything

On any device on the router's Wi-Fi, open a browser to http://192.168.8.1:8080. Live units and your own position, on your offline map.

On a phone, type the http:// so it doesn't force https.
13

Name your units (optional)

Back in Lookout Manager → Name units: give each ID a friendly name. It shows on the map within seconds.

14

Run it anywhere

Power it from 12 V in a truck — no internet, ever. Pull the power and plug it back in: it comes up on its own.

Plug-and-forget. Survives a power cut.
That's it — the fleet and you, live, on an offline map, on any screen.
