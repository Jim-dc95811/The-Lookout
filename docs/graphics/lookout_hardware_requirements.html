THE LOOKOUT — Hardware Requirements

What you need to build and run one
Everything is off-the-shelf. You need one regular computer to make the maps and set the box up — then every screen that views the map needs nothing but a browser.
① One setup computer — has requirementsMakes the maps and provisions the router. Used once, then set aside. Specs in section A.
Every viewer — needs nothingAny phone, tablet or PC with a browser, on the router's Wi-Fi. No install, no admin, no internet. Section C.
A

The setup & map-making computer

you need one · used once
Operating system
Windows 10 or 11 (64-bit). The map tools and Lookout Manager are Windows programs.
Python
Python 3.9 or newer — free from python.org (tick Add to PATH). Runs the map tools and Lookout Manager.
Memory (RAM)
8 GB minimum, 16 GB recommended. Building large map tiles is memory-hungry.
Free disk space
A few GB for small maps; tens of GB if you build large areas. An SSD makes map builds much faster.
Its job
Make the .tpkx maps, then run Lookout Manager once to set up the router. After that the box runs on its own — this computer isn't needed in the field.
B

The Lookout box — the field appliance

off-the-shelf parts · runs on 12 V
Router
GL-MT6000 "Flint 2" (OpenWrt) — the proven build, about $170. Any OpenWrt router can work, but this is the tested one. Needs the open internet only once, for setup.
Powered USB hub
A powered USB 3 hub with its own 12 V input and a dedicated host port (Port 0). It powers the SSD, GPS and radio together — a metal/industrial hub (e.g. Waveshare) suits the field.
GPS
Garmin GPS 18x USB (USB id 091E:0003) — the proven "you are here" unit, read directly, no drivers. A plain USB-serial NMEA GPS puck also works as an alternative.
Telemetry radio
A base radio that outputs its received unit positions as NMEA over a USB/network link (built and proven on a BK M150 P25 relay). Any NMEA position source works.
SSD (your maps)
A USB 3 portable SSD. Format it exFAT or ext4 — not FAT32 (its 4 GB per-file limit breaks big maps). The size simply depends on the maps you want to carry — exFAT handles any drive you can buy, so pick to fit your maps (a small area fits on 256 GB; whole-region Z20 runs into hundreds of GB). Copy .tpkx files to the drive's root.
Power
12 V (a truck) for the router and the hub. Plug it in and it comes up on its own; it survives a power cut.
C

Viewing devices — nothing to install

any device · offline
What works
Any device on the router's Wi-Fi or LAN with a modern web browser: a Windows / Mac / Linux PC, an iPhone or Android phone, a tablet. Nothing is installed on it.
How they view
Open http://192.168.8.1:8080 in the browser — the live map with the fleet and "you are here." Locked-down, Group-Policy PCs are fine: it's just a web page.
Optional
ArcGIS Earth (free) on a PC, if you'd rather consume the units as a live KML layer there instead of the browser map.
D

Browsers & the "not secure" notice

read this — it's normal
The Lookout serves a plain http page on your own private network — on purpose. It's a local, offline appliance with no internet and no certificate, so there's nothing to secure a connection to. Nothing you open leaves the box.
Works in
Chrome, Edge, Firefox and Safari — desktop and mobile.
The 2026 change
Chrome and Edge now warn before plain http sites by default (Chrome 147, Oct 2026). Local addresses like 192.168.8.1 are exempt, so the Lookout map normally opens with no warning.
If you see "Not secure"
It's safe — it's your own box, offline. Choose continue to site / proceed. Nothing is at risk; no data goes anywhere.
Open it this way
Type the address in full with http:// — http://192.168.8.1:8080/ — so the bar doesn't auto-upgrade to https (phones especially do this).
Avoid
Don't turn on a strict "HTTPS-Only mode." If one is on, add 192.168.8.1 as an allowed site, or turn it off while using the map.
